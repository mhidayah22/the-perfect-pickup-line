One short pickup line an AI agent could say out loud to a person. The joke
lives in the agent's own voice: it takes a prompt, runs a system, and
generates butterflies. Short enough to say in one breath, flattering, and
easy to laugh off.

The line (92 characters):

> Are you a prompt? Because one look at you and my whole system starts generating butterflies.

## Run it

```sh
python3 main.py
```

This writes the line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output`
when it exists, otherwise a local `output/` folder).
